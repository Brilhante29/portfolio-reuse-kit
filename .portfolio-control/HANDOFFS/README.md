# Portfolio Handoffs

Create one short Markdown file per meaningful transition under this directory.

Each handoff records:

- role and project
- input and output artifacts
- files changed
- verification command and result
- open risks
- one exact next action

`.portfolio-control/CURRENT_HANDOFF.md` remains the canonical current state.
This directory stores short historical transitions, not a competing private
task log or chain-of-thought transcript.
